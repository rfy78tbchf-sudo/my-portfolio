# Build83 — Write a holding reason, then review it

The start button opens the existing reason editor inside the start card. Blank
reasons stay in the editor with an actionable prompt. After saving and reloading
the reason, a single explicit AI review action is shown at the start; saving alone
does not generate AI or save a decision. Optional fields and version history stay
collapsed. Late save responses cannot update another security detail.

No server, accounting, authentication or model changes. Isolated mobile fixtures
cover empty input, save/reload, summary update and next action at three widths.
