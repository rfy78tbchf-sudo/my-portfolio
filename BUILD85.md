# Build85 — Finish a decision review

Choice-specific reason/review placeholders clarify the two required fields without
prefilling or replacing the user's words. The save button names the selected
choice. Only after the existing save/readback verification succeeds, show a plain
completion message and a return-to-list action using the shared modal close path.
Failed or mismatched readbacks retain the draft and do not show completion.

No backend, model or accounting changes. Mobile fixtures check guidance, draft
preservation, failed readback, successful completion/close and saved reopening.
