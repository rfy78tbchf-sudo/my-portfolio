# Build106 — Recent confirmed swing peak

Supersedes the Build105 52-week-high watch. The home watch and security chart now use the same pure recentSwingPeak function on the latest 160 stored closes. Candidates are within the latest 120 observations and require 20 preceding observations. A candidate is no lower than the preceding five closes and strictly above the next five; it must be at least 5% above the preceding twenty-close minimum and fall at least 3% within the next five observations. Pick the most recent qualifying candidate, including a lower high; ties resolve to the last plateau point. Confirmation occurs only after five following observations. Any later close above that peak retires it until a newer peak qualifies.

This is an explicit application heuristic, not a universal definition of a swing high. Uses closes, not intraday highs. Dates must be valid and strictly increasing, prices positive, and currency consistent. Gaps over ten calendar days or optional source changes invalidate the input. Trading-calendar completeness and split-adjustment are not established. Missing/invalid/old prices and pending/broken peaks remain unknown, not zero decline. The home threshold remains -15%, and only matching holdings are shown; the chart shows an identified peak even at a smaller drawdown.

Read path: reuse the existing authenticated daily_security_prices REST access, selecting only date/close/currency for each positive held security, 160 rows per security, at most three requests concurrently. Each failed request becomes an empty series and cannot clear unrelated account data. No schema, credentials, authorization, accounting or personal records changed. Existing security-detail prices use the same 160-row suffix and calculator.

UI: recent peak price/date alongside each home row; same date/price and a labelled chart dot in security detail. Panning outside the peak hides its dot while keeping the textual basis. Zooming never recomputes the peak from the visible range.

Verification: deterministic threshold, local-versus-global maximum, latest lower peak, five-observation confirmation, breakout retirement, invalid/missing/duplicate/mixed-currency data, stale/future observations, multi-account deduplication and bounded optional-fetch tests. Synthetic production-renderer tests at 390/402/430px cover home -> chart, peak marker, zoom/pan/reset and existing decision/portfolio/performance flows. Existing 360/390/430px chart touch/pinch/MA/period checks are retained. Read-only production SQL confirms the existing detail RPC and the price query fields; ARM stored history yields a 2026-09-22 close peak of 333.20 USD, confirmed 2026-09-29, versus 2026-09-30 close 289.66 USD (-13.0672%). This checks stored data, not a signed-in iPhone run or independent market-price validation.
